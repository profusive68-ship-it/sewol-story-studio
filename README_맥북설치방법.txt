세월의 사연극장 — 맥북 원클릭 자동화 패키지
설치 및 사용 설명서 (v1.0.0)
======================================================================

이 폴더 하나로 ‘사연 라디오 드라마’ 한 편을 끝까지 만듭니다.
  대본 → 성우 녹음 → 장면 이미지 → BGM·효과음 → 영상 → 썸네일 2종
  → 유튜브 제목·설명·채널 전략 → 예약 업로드 → 첫 댓글 → 50초 쇼츠

프로그램과 내 데이터는 완전히 분리되어 있어, 새 버전으로 덮어써도
설정·영상·대본은 사라지지 않습니다.


────────────────────────────────────────────────────────────
1. 준비물
────────────────────────────────────────────────────────────
· macOS 12 이상 (Apple Silicon / Intel 모두 가능)
· Python 3.10 이상  →  https://www.python.org/downloads/macos/
· ffmpeg           →  터미널에서  brew install ffmpeg
   (Homebrew 가 없다면 https://brew.sh 안내대로 먼저 설치)
· Gemini API 키(선택) → https://aistudio.google.com → Get API key
· 유튜브 자동 업로드(선택) → Google Cloud 에서 client_secret.json 발급 (아래 6장)


────────────────────────────────────────────────────────────
2. 설치 (두 가지 방법 중 하나)
────────────────────────────────────────────────────────────
[A] ZIP 으로 받은 경우
  ① 압축을 풉니다. (예: 바탕화면/세월의사연극장)
  ② start.command 를 더블클릭합니다.
     - "확인되지 않은 개발자" 경고 → start.command 오른쪽 클릭 → [열기] → [열기]
     - "실행 권한이 없습니다" → 터미널에서:
         chmod +x "/경로/세월의사연극장/start.command"
  ③ 처음 3~5분 자동 설치 후 브라우저가 열립니다.
         http://localhost:8765
     (포트가 사용 중이면 8766, 8767 로 자동 변경 — 터미널에 표시됩니다)

[B] 깃허브에서 받는 경우 (업데이트가 가장 쉬움)
  터미널에서 아래 두 줄:
     git clone https://github.com/profusive68-ship-it/sewol-story-studio.git
     cd sewol-story-studio && ./start.command

※ 작업 중에는 터미널 창을 닫지 마세요. 창을 닫으면 스튜디오가 꺼집니다.
※ 두 번째 실행부터는 설치 없이 10초 안에 열립니다.

3. 내 데이터는 어디에 있나요? (업데이트해도 안전)
────────────────────────────────────────────────────────────
프로그램(덮어써도 되는 부분)
  app/ · static/ · assets/ · sfx_library/ · tools/
  start.command · README_맥북설치방법.txt · requirements.txt

내 데이터(절대 지우지 않는 부분)
  config/    ← API 키, 유튜브 토큰, 접속 비밀번호, 스케줄, 발음사전
  projects/  ← 만든 모든 사연(대본·이미지·음성·영상·썸네일·카피)
  assets_inbox/ ← 케빈이 깃허브로 보내온 이미지 묶음

이 두 폴더는 .gitignore 로 깃허브에 올라가지 않습니다.
백업은 config/ 와 projects/ 만 복사하면 됩니다.

▶ 업데이트 방법 (10초)
  · 대시보드 위 [🔄 최신 버전·이미지 받기] 버튼 → 자동으로 git pull
  · 또는 터미널:  cd sewol-story-studio && git pull --ff-only
  · ZIP 으로 설치했다면: 새 ZIP 을 풀어 app/, static/, assets/, sfx_library/,
    start.command, requirements.txt 만 덮어쓰기 (config/, projects/ 는 그대로 둠)

4. 화면 사용법 (초보자 순서)
────────────────────────────────────────────────────────────
[0] Gemini API 설정
    키를 붙여넣고 [저장] → [연결 테스트].

[1] 사연 & 포맷

    · 길이: 50초 쇼츠 · 5분 파일럿 · 20분 중편 · 40분 본편 · 주말 2시간 합본
    · 첫 15초 반전 훅: 0초부터 절정 장면으로 시작 (인사·소개 없음)
    · 엔딩 예고: ① 6개월 뒤 후속편 복선 ② 다음 사연 자동 추천 ③ 직접 입력

[2] 목소리·진행자·자막

      ※ BongJin 음성이 제공되지 않으면 자동으로 낮은 톤 대체 음성 사용
    · 낭독 속도 -5% ~ +10%
    · 우측 하단 원형 진행자(남/여 기본 또는 내 사진)
    · 자막 시니어 특대 92px / 기본 70px, 10~14자 자동 줄바꿈

[3] 참여 유도 (라디오처럼 ‘듣는’ 영상)
    · 중반 좋아요 멘트(음성): 55% 지점, 해설자가 직접 부탁
    · 중반 좋아요 배너(화면): 같은 시점 5초
    · 엔딩 구독·지역 인사·사연 제보(음성): 영상 맨 끝에서만
    · 마지막 10초 최종화면: 구독 원형·다음 영상 카드 자리를 비워 둔 레이아웃
    · 취침용 빗소리 엔딩(마지막 20~30초)
    모든 멘트는 직접 고쳐 쓸 수 있습니다.

[4] 이미지 & 제작
    ● 모드 A (완전자동): Gemini 가 대본+이미지까지 만들고 바로 영상 완성
    ● 모드 B (0원 협업): [대본 + 이미지 요청서] → 케빈에게 요청서 전달
       → 받은 s01.png… 를 화면에 끌어다 놓기 → [영상 조립]

[5] 실시간 진행

5. 유튜브 자동 업로드 · 첫 댓글 · 채널 전략
────────────────────────────────────────────────────────────
① client_secret.json 무료 발급 5단계
   1) console.cloud.google.com → 새 프로젝트 (예: 세월의사연극장)
   2) API 및 서비스 → 라이브러리 → YouTube Data API v3 → 사용 설정
   3) OAuth 동의 화면 → 외부(External) → 앱 이름·이메일 → 테스트 사용자에 내 계정
   4) 사용자 인증 정보 → OAuth 클라이언트 ID → 애플리케이션 유형 ‘데스크톱 앱’
      → JSON 다운로드 (파일 이름 client_secret.json)
   5) 대시보드 [유튜브 자동 업로드] → ①에 파일 올리기 → ② [채널 연동] → 구글 로그인

② 공개 방식
   · 예약 공개: 지금 비공개로 올리고, 정한 시각에 자동 공개(publishAt)
   · 즉시 공개 / 일부 공개 / 비공개
   · 영상 완성 후 자동 업로드 ON/OFF
   · 제목 1~3안 중 선택, 설명문(챕터+해시태그), 썸네일까지 자동 반영

③ 첫 댓글 자동 게시 (항상 내 댓글이 1등)
   · 즉시 공개: 업로드 직후 바로 댓글 등록
   · 예약 공개: 공개 10초 전부터 10~15초 간격으로 상태를 확인하다가,
     공개로 바뀌는 즉시 댓글을 등록합니다.
   · YouTube API 에는 ‘고정(pin)’ 기능이 없습니다. 자동 게시 후
     유튜브 앱/웹에서 그 댓글을 1번 눌러 [고정]만 해주세요.
     (대시보드에 “첫 댓글 자동 게시 완료 · 핀만 1클릭” 표시)

④ 채널 전략 분석
   · 연동된 채널의 업로드 시간·조회수·제목 패턴을 분석해 3가지 제안
     ① 최적 시간 + 다음 사연  ② 장르 집중 편성  ③ 주말 합본 조합
   · [✅ 승인하고 바로 진행] → 그대로 제작·합본·예약 업로드까지 실행
   · 채널이 없으면 이 맥북의 제작 이력 + 시니어 사연 벤치마크로 제안

⑤ 댓글 관리
   · 최신 댓글 목록 → [초안 만들기] → 시니어 눈높이 답글 → [답글 등록]

⑥ 50초 쇼츠 추출
   · 완성된 롱폼에서 가장 임팩트 있는 45~55초를 골라
     1080×1920 세로 + 상단 2줄 제목 + 중앙 크롭 + 하단 자막으로 자동 렌더

⑦ 정직한 안내 — 구글 ‘테스트(Testing)’ 상태
   구글 심사를 받지 않은 앱은 YouTube 정책상 업로드 영상이 ‘비공개’로
   고정될 수 있고, 예약 공개가 자동으로 풀리지 않을 수 있습니다.
   공개가 필요하면 Google Cloud OAuth 동의 화면에서 앱을 ‘게시(Production)’하고
   필요 시 구글 검증을 받아야 합니다. 검증 전에는 [비공개]로 올린 뒤
   유튜브 스튜디오에서 직접 공개하는 방법이 가장 안전합니다.
   · 업로드 1회에 API 할당량 1,600 사용 (기본 하루 10,000 → 약 6편)

6. 폰에서 접속 · 잠자기 방지 · 자동 스케줄
────────────────────────────────────────────────────────────
[폰 접속]
  · 집(같은 와이파이): 대시보드 [📱 폰에서 접속하기]의 첫 번째 주소
    (예: http://192.168.0.12:8765) 를 폰 브라우저에 입력하거나 QR 촬영
  · 외출: 맥과 폰에 Tailscale(무료) 설치·같은 계정 로그인 → 맥에서 켜기
    → 두 번째 주소 사용 (공유기 포트포워딩은 열지 마세요)
  · 접속 비밀번호(숫자 4~8자)를 켜면 주소 뒤에 ?pin=숫자 가 자동으로 붙습니다.
  · [잠자기 방지(caffeinate)] 를 켜면 화면만 꺼지고 서버는 계속 살아 있습니다.

[자동 스케줄]
  · 매일 만드는 시각(예 04:00) + 공개 예약 시각(예 21:00) + 기본 장르·길이
  · 대시보드가 켜져 있는 동안 매일 자동 실행됩니다.
  · 맥이 꺼져도 자동 실행하려면 아래 launchd 설정을 한 번 실행:
       tools/launchd_설치.command 더블클릭
    → 맥이 켜질 때마다 대시보드 서버가 자동으로 켜지고 계속 살아 있습니다.
    해제:  launchctl unload ~/Library/LaunchAgents/com.sewol.studio.plist

10. 자주 겪는 문제
────────────────────────────────────────────────────────────
▶ “ffmpeg 를 찾지 못했습니다” → brew install ffmpeg 후 다시 실행
▶ 브라우저가 안 열려요 → 터미널에 표시된 http://localhost:8766 직접 입력
▶ “이미지 N장이 없습니다” → 모드 B는 이미지가 모두 있어야 조립합니다.
   이름은 s01.png, s02.png … (요청서와 동일)
▶ 성우 음성이 안 나와요 → edge-tts 는 인터넷 필요. 이미 만든 음성은 재사용됩니다.
▶ 자막이 네모로 보여요 → assets/fonts/GmarketSansBold.ttf 확인
▶ 렌더가 오래 걸려요 → 40분 본편은 맥 사양에 따라 40~90분. 창을 닫지 마세요.
   Apple Silicon 은 하드웨어 가속(h264_videotoolbox) 자동 사용.
▶ 유튜브 업로드가 ‘비공개’로만 돼요 → 5장 ⑦ 구글 테스트 상태 안내 참고
▶ 댓글이 자동으로 안 달려요 → 채널을 댓글 권한 포함으로 다시 연동
   (유튜브 채널 연동을 다시 누르면 권한을 새로 받습니다)
▶ 폰에서 접속이 안 돼요 → 같은 와이파이인지, 맥 방화벽에서 Python 허용,
   접속 비밀번호를 켰다면 주소의 ?pin=숫자 확인
▶ 화면이 깨져 보여요 → Command+Shift+R 새로고침
