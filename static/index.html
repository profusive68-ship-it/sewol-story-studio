🎙️ 음성 엔진 (감성 TTS)

        무료 edge-tts
      

      
성우 목소리를 만드는 엔진을 고릅니다. OpenAI 감성 TTS는 대사마다 감정 연기 지시를 넣어
        사람이 읽는 듯 훨씬 자연스럽습니다(유료 · 편당 몇백 원). 무료 edge-tts는 0원으로 바로 쓰는 기본 음성입니다.

      

        
        
      

      
      

        
        
        
      

      

        키 발급: platform.openai.com/api-keys
        → Create new secret key → 복사해서 위 칸에 붙여넣기. 키는 이 맥북 config.json 에만 저장됩니다.
