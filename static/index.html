5 유튜브 자동 업로드

확인 중

영상이 완성되면 정한 시간에 맞춰 유튜브에 올리고, 예약 공개로 바꿔 둡니다. 제목·설명·썸네일까지 자동으로 들어갑니다.

아직 올리지 않았습니다.

연결 안 됨
client_secret.json 무료 발급 5단계
  1. console.cloud.google.com 접속 → 새 프로젝트 만들기 (이름 예: 세월의사연극장)
  2. API 및 서비스 → 라이브러리 → YouTube Data API v3 검색 → 사용 설정
  3. API 및 서비스 → OAuth 동의 화면 → 외부(External) → 앱 이름·이메일 입력 → 저장 → 테스트 사용자에 내 구글 계정 추가
  4. 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 애플리케이션 유형 데스크톱 앱 → 만들기 → JSON 다운로드
  5. 받은 파일 이름이 client_secret.json 인지 확인 → 위 ①에 올리기

정직한 안내: 구글 심사를 받지 않은 ‘테스트(Testing)’ 상태의 앱에서는 YouTube 정책상 업로드된 영상이 비공개로 고정될 수 있습니다. 이 경우 예약 공개가 자동으로 풀리지 않습니다. 공개가 필요하면 Google Cloud 의 OAuth 동의 화면에서 앱을 ‘게시(Production)’하고 필요 시 구글 검증을 받아야 합니다. 검증 전에는 [비공개]로 올려 두고, 유튜브 스튜디오에서 직접 공개하는 방법이 가장 안전합니다.

업로드 1회에 YouTube API 할당량 1,600이 쓰입니다. 기본 하루 10,000 → 하루 6편 정도입니다. 예약은 ‘지금 비공개 업로드 → 정한 시각에 자동 공개’ 방식입니다.
